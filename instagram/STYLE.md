# riyad_31mh — house style (chosen: version 1, "Keynote white")

Applies to every new Instagram post unless the owner asks otherwise.

## Rules
1. **Always open with a hook.** Slide 1 is a hook only: a short, surprising line that makes people swipe.
   Prepare several hook options (about 5) for the owner to choose from.
2. **Carousel format:** 1080×1350, usually 6 slides: hook, then explanation, then practical steps, then a summary with a call to action (save / share / follow).
3. **No AI-generated images.** Use real Apple emoji (iamcal/emoji-data `img-apple-160`), real photos
   from open sources, and UI elements drawn in code.
4. **Facts:** check numbers against sources before using them; avoid made-up statistics.

## Look
- Background `#ffffff`; panels `#f5f5f7`; text `#1d1d1f`; secondary `#6e6e73`; tertiary `#86868b`; one blue accent `#0071e3` used only for the text cursor.
- Black and white only. No other colours apart from the emoji.
- Everything is centred: a gray eyebrow label, then one large emoji (170–200px), then a bold headline, then a gray subtitle, then one simple UI element.
- Fonts: IBM Plex Sans Arabic (headline 700, 84–100px; body 400, 32px). Inter for Latin text and numbers.
- Footer: `riyad_31mh · اسحب ←` plus progress dots; the last slide shows only the handle.
- Reference implementation: `passwords-post/post.html`.
